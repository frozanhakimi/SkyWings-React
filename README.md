# ✈️ SkyWings Airlines — React App

A modern airline booking web application built with **React + Vite**.

---

## 📖 About

SkyWings Airlines simulates a complete airline system with 12 pages:
login, signup, dashboard, flights, bookings, shop, destinations,
profile, safety, loyalty program, and live flight tracking.

All pages are fully responsive and use real interactive charts
and an animated world map.

---

## 🛠️ Technologies

- **React 19** — UI components
- **Vite** — Build tool
- **React Router v7** — Navigation
- **Chart.js + react-chartjs-2** — Real charts
- **react-simple-maps** — World map
- **CSS3** — Custom styling and animations
- **SVG** — Icons and airline logos
- **Git & GitHub** — Version control
